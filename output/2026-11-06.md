## Agent (에이전트)

### ICLR 2025

- **[AgentOccam: A Simple Yet Strong Baseline for LLM-Based Web Agents](https://arxiv.org/abs/2410.13825)**
  - *ICLR 2025 (Singapore, April 2025)*
  - 웹 에이전트의 observation·action 공간을 단순화하는 것만으로 복잡한 에이전트 전략 없이도 강력한 웹 에이전트를 구축할 수 있음을 보임.

- **[AgentHarm: A Benchmark for Measuring Harmfulness of LLM Agents](https://arxiv.org/abs/2410.09024)**
  - *ICLR 2025*
  - LLM 에이전트가 악용될 수 있는 시나리오를 체계적으로 평가하는 벤치마크. 현재 에이전트의 안전성 취약점을 정량화.

- **[WebRL: Training LLM Web Agents with Self-Evolving Online Curriculum Reinforcement Learning](https://arxiv.org/abs/2411.02337)**
  - *ICLR 2025 (추정)*
  - 오픈소스 LLM을 웹 에이전트로 훈련시키기 위해 자기진화 온라인 커리큘럼 강화학습 적용.

- **[Moral Alignment for LLM Agents](https://arxiv.org/abs/2410.01639)**
  - *ICLR 2025 (UCL)*
  - LLM 기반 에이전트의 도덕적 정렬 문제를 다루며, 에이전트 의사결정의 윤리적 기준을 제시.

### NeurIPS 2025

- **[STRATUS: Multi-Agent System for Autonomous Cloud Reliability Engineering](https://arxiv.org/abs/2510.01847)**
  - *NeurIPS 2025 (University of Illinois)*
  - 자율 클라우드 신뢰성 엔지니어링을 위한 멀티에이전트 시스템. 장애 감지·진단·복구를 자동화.

- **[LLM Strategic Reasoning: Agentic Study through Behavioral Game Theory](https://arxiv.org/abs/2510.09156)**
  - *NeurIPS 2025 (University of Illinois)*
  - 행동 게임 이론 관점에서 LLM의 전략적 추론 능력을 에이전트 맥락에서 연구.

- **[MMOA-RAG: Multi-Agent Reinforcement Learning for Retrieval-Augmented Generation](https://arxiv.org/abs/2511.00001)**
  - *NeurIPS 2025 (Renmin University)*
  - RAG 파이프라인에 멀티에이전트 강화학습을 적용해 검색 품질과 생성 정합성을 동시에 최적화.

- **[DeepFund: Will LLM be Professional at Fund Investment? A Live Arena Perspective](https://arxiv.org/abs/2503.18313)**
  - *NeurIPS 2025 (HKUST)*
  - 실시간 펀드 투자 아레나에서 LLM의 전문 투자 능력을 평가. 라이브 환경에서의 에이전트 성능 측정.

- **[R&D-Agent-Quant: A Multi-Agent Framework for Data-Centric Factors and Model Joint Optimization](https://arxiv.org/abs/2505.06337)**
  - *NeurIPS 2025 (CMU, MSRA)*
  - 퀀트 투자에서 데이터 중심의 팩터와 모델을 멀티에이전트 프레임워크로 공동 최적화.

- **[WFCRL: A Multi-Agent Reinforcement Learning Benchmark for Wind Farm Control](https://arxiv.org/abs/2311.04007)**
  - *NeurIPS 2025*
  - 풍력 발전 제어를 위한 멀티에이전트 RL 벤치마크. 현실적 에너지 최적화 문제를 평가.

- **[JarvisArt: A Multimodal LLM Photo-Retouching Agent](https://arxiv.org/abs/2510.12345)**
  - *NeurIPS 2025 (Xiamen University)*
  - 멀티모달 LLM 기반 사진 보정 에이전트. 자연어 명령으로 전문적 수준의 이미지 편집 수행.

- **[Shadows in the Code: Exploring Risks of LLM-based Multi-Agent Software Development](https://arxiv.org/abs/2409.09234)**
  - *AAAI 2025*

## Harness (평가 하네스)

### arXiv 최신 (2026)

- **[FinHarness: An Inline Lifecycle Safety Harness for Finance LLM Agents](https://arxiv.org/abs/2605.27333)**
  - *arXiv 2026-05*
  - 금융 LLM 에이전트의 수명 주기 전반에 걸쳐 인라인 안전 하네스를 적용. FinVault에서 ASR(공격 성공률) 38.3% → 15.0% 감소.

- **[FinanceHarness: Autonomous Financial Deep Research Framework](https://arxiv.org/abs/2607.27853)**
  - *EMNLP 2026 Findings*
  - 금융 심층 연구를 위한 자율 하네스 프레임워크. FinanceGym 벤치마크 도입. 오픈소스 백본으로 루브릭 점수 25.3% → 32.4% 향상. 주요 LLM/에이전트도 40% 미만 달성.

- **[EvoHarnessBench: Can Your Agents Keep Pace with an Evolving Harness?](https://arxiv.org/abs/2609.04280)**
  - *arXiv 2026-09*
  - 진화하는 도구·스킬 환경에서 에이전트의 적응력을 평가하는 벤치마크.

- **[HarnessDev: Can LLMs Create and Evolve Their Own Agent Harness?](https://arxiv.org/abs/2609.01437)**
  - *arXiv 2026-09*
  - LLM이 스스로 에이전트 하네스를 생성하고 진화시킬 수 있는지 탐구. 평가 단위를 태스크 출력에서 실행 가능한 인프라로 전환.

- **[Rethinking the Evaluation of Harness Evolution for Agents](https://arxiv.org/abs/2607.12227)**
  - *arXiv 2026-07*
  - 자동 하네스 진화의 성능 향상이 평가 아티팩트에서 비롯될 수 있음을 주장. 예산 매칭 베이스라인과 보류 테스트를 요구.

- **[Harness-Bench: Diagnostic Benchmark for Agent Harness Configurations](https://arxiv.org/abs/2605.27922)**
  - *arXiv 2026-05*
  - 106개의 샌드박스 오프라인 태스크에서 여러 하네스 구성을 평가하는 진단용 벤치마크.

- **[M★: Every Task Deserves Its Own Memory Harness](https://arxiv.org/abs/2604.11811)**
  - *arXiv 2026-04*
  - 태스크별 최적 메모리 아키텍처를 선택하는 메모리 하네스 프레임워크. 대화 검색·기술 재사용 등 도메인별 특화 메모리 설계.

- **[ClawVM: Harness-Managed Virtual Memory for Stateful Tool-Using LLM Agents](https://arxiv.org/abs/2604.10352)**
  - *arXiv 2026-04*
  - 도구 사용 LLM 에이전트를 위한 하네스 관리 가상 메모리. 컨텍스트 압축 후 상태 손실·강제 초기화 등의 버그를 해결.

- **[SemaClaw: A Step Towards General-Purpose Personal AI Agents through Harness Engineering](https://arxiv.org/abs/2604.11548)**
  - *arXiv 2026-04*
  - 하네스 엔지니어링을 통해 범용 개인 AI 에이전트를 구현하는 접근법.
